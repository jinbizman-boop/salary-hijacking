개인정보처리방침

이 문서는 현재 제공되는 정적 홈페이지 시안의 실제 동작을 기준으로 작성되었습니다. 운영 서버와 앱 서비스가 연결될 때에는 실제 수집 항목과 처리 구조에 맞춰 별도 고지합니다.

목차 1. 적용 범위 2. 처리 항목 3. 처리 목적 4. 저장 위치·기간 5. 이용자 권리 6. 안전성 조치 7. 문의처

시행일: 2026년 8월 4일 · 본 정적 시안은 문의 정보를 외부 서버로 전송하지 않습니다.

1. 적용 범위

본 방침은 진비즈 매니지먼트가 제공하는 급여납치 공식 홈페이지 정적 시안에 적용됩니다. 현재 패키지는 로컬 또는 정적 호스팅에서 실행되는 HTML·CSS·JavaScript 파일로 구성되어 있습니다.

2. 처리하는 정보

메인 페이지의 제휴 문의 양식에서 사용자가 직접 입력한 다음 정보를 브라우저에 임시 저장할 수 있습니다.

  • 회사·기관명, 담당자명
  • 이메일, 선택 입력한 연락처
  • 문의 유형, 제안 내용
  • 개인정보 수집·이용 안내 동의 여부
  • 정적 시안이 생성한 접수 예시번호와 저장 시각

쿠키, 광고 식별자, 위치정보, 급여·대출·저축 데이터는 이 정적 홈페이지 시안에서 수집하지 않습니다.

3. 처리 목적

입력 정보는 문의 양식의 화면 흐름과 유효성 검증, 브라우저 임시 저장 동작을 확인하기 위한 프로토타입 목적으로만 사용됩니다. 실제 제휴 문의 접수나 회신 처리에는 사용되지 않습니다.

4. 저장 위치와 보유 기간

문의 내용은 사용 중인 브라우저의 localStorage에만 저장되며 외부 서버로 전송되지 않습니다. 최대 최근 20개의 문의 시안이 저장되고, 브라우저 사이트 데이터 삭제 또는 저장소 초기화 시 함께 삭제됩니다.

5. 이용자의 권리와 행사 방법

브라우저 설정에서 해당 사이트의 저장 데이터 또는 전체 사이트 데이터를 삭제하면 임시 저장된 문의 내용을 즉시 삭제할 수 있습니다. 외부 서버에는 정보가 전달되지 않으므로 별도의 서버 삭제 요청 대상은 없습니다.

6. 안전성 확보 조치

  • 사용자 입력은 화면에 HTML로 삽입하지 않고 텍스트로만 처리합니다.
  • 외부 분석 도구, 광고 스크립트, 원격 폰트와 CDN을 사용하지 않습니다.
  • 실제 서비스 연동 전에는 전송구간 암호화, 서버 접근통제, 보유기간, 파기 절차를 별도로 설계해야 합니다.
