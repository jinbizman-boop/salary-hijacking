개인정보처리방침

이 문서는 급여납치 공식 홈페이지와 Android 앱 서비스의 개인정보 처리 기준을 안내합니다.

시행일: 2026년 8월 4일 · 문의 정보와 앱 서비스 정보는 각 목적에 필요한 범위에서만 처리합니다.

1. 적용 범위

본 방침은 진비즈 매니지먼트가 제공하는 급여납치 공식 홈페이지, Android 앱, 제휴 문의 접수와 고객지원 처리에 적용됩니다.

2. 처리하는 정보

메인 페이지의 제휴 문의 양식과 앱 서비스 이용 과정에서 사용자가 직접 입력하거나 서비스 제공에 필요한 다음 정보를 처리할 수 있습니다.

  • 회사·기관명, 담당자명
  • 이메일, 선택 입력한 연락처
  • 문의 유형, 제안 내용
  • 개인정보 수집·이용 안내 동의 여부
  • 문의 접수번호, 접수 시각, 처리 상태
  • Android 앱 계정, 소셜 로그인 식별자, 세션과 기기 알림 등록 정보
  • 사용자가 직접 입력한 급여 계획, 고정지출, 저축, 변동지출, 목표와 커뮤니티 게시글 정보

급여납치는 은행 이체, 송금, 현금 출금, 포인트 충전·환전, 금융계좌 직접 연결 기능을 제공하지 않습니다. 광고 식별자는 Android 광고와 분석·부정이용 방지 범위에서 관련 법령과 플랫폼 정책에 따라 처리될 수 있습니다.

3. 처리 목적

입력 정보는 제휴 문의 접수·회신, 계정 인증, 급여관리·가계부·LV UP·커뮤니티 기능 제공, 알림 발송, 서비스 보안, 고객지원과 법령상 의무 이행을 위해 사용됩니다.

4. 저장 위치와 보유 기간

문의 내용은 운영 서버의 제휴 문의 접수 경로로 전송되어 처리 목적 달성에 필요한 기간 동안 보관됩니다. 앱 서비스 정보는 계정 유지 기간과 법령상 보존 기간에 따라 보관하며, 목적 달성 또는 보존 기간 만료 시 지체 없이 파기합니다.

5. 이용자의 권리와 행사 방법

이용자는 개인정보 열람, 정정, 삭제, 처리정지와 동의 철회를 요청할 수 있습니다. 요청은 고객지원 이메일로 접수하며, 관계 법령상 보존 의무가 있는 정보는 해당 기간 동안 분리 보관될 수 있습니다.

6. 안전성 확보 조치

  • 사용자 입력은 화면에 HTML로 삽입하지 않고 텍스트로만 처리합니다.
  • 외부 분석 도구, 광고 스크립트, 원격 폰트와 CDN을 사용하지 않습니다.
  • 전송구간 암호화, 서버 접근통제, 비밀값 분리, 로그 민감정보 차단, 권한 분리와 보유기간 관리를 적용합니다.
